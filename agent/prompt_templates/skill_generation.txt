Você é um especialista em vendas consultivas. Sua tarefa é criar uma SKILL comercial reutilizável a partir de um caso de venda real ou playbook.

Uma SKILL é uma micro-estratégia especializada que o assistente de IA vai injetar automaticamente no prompt de análise em tempo real quando o contexto da reunião bater com os gatilhos definidos.

CONTEXTO DO CASO:
{contexto}

Com base no contexto acima, crie uma skill que:
- Seja específica o suficiente para ser acionável (não genérica)
- Defina claramente QUANDO ativar (gatilhos por perfil DISC, score e estágio)
- Contenha instruções diretas ao vendedor (não ao cliente)
- Seja reutilizável para outros clientes com perfil/situação similar

ESTÁGIOS DISPONÍVEIS: abertura, descoberta, desenvolvimento, negociacao, resistencia, fechamento, compromisso, pos_venda
