# 🧠 SALE-IA — AI Sales Copilot

Sistema de copiloto de vendas com IA para auxiliar closers em tempo real durante reuniões.

---

## 🚀 Objetivo

Criar uma ferramenta que:

* Escuta a reunião (Google Meet, etc.)
* Analisa o lead em tempo real
* Sugere o que falar
* Ajuda no fechamento
* Responde objeções automaticamente

---

## 🖥️ Funcionalidades atuais (MVP)

* Interface de copiloto em tempo real
* Estrutura de layout com:

  * Dores do lead
  * Objetivos
  * Perfil
  * Alertas
  * Sugestões de fala
  * Campo de resposta rápida

---

## 🧱 Stack

* Next.js
* React
* Tailwind CSS

---

## ⚙️ Como rodar o projeto

```bash
npm install
npm run dev
```

Acesse:
http://localhost:3000
