O que é o SALEIA

O SALEIA é um assistente de vendas com inteligência artificial que opera em tempo real durante reuniões no Google Meet. Ele escuta a conversa com o cliente, analisa o comportamento e o perfil do comprador, extrai informações financeiras, detecta objeções e sugere ao vendedor a próxima fala — tudo isso enquanto a reunião acontece, sem interromper a conversa.


Ao final de cada reunião, gera automaticamente um relatório completo com recapitulação emocional, diagnóstico financeiro, perfil comportamental DISC e probabilidade de fechamento. Na versão 1.3.3, o sistema conta também com autenticação de usuários, painel administrativo e o módulo Condução — que gera scripts de venda ao vivo diretamente no cenário da reunião.

Como Funciona
1

Acesso via login autenticado

O vendedor acessa a plataforma pelo navegador, faz login com e-mail e senha, e é redirecionado para o dashboard. Cada usuário tem um perfil (admin, gerente ou usuário) que define o que pode acessar.

2

Extensão Chrome instalada no navegador do vendedor

A extensão SALEIA é ativada automaticamente ao entrar no Google Meet — aparece uma barra lateral discreta na lateral da tela com o painel ao vivo.

3

Captura das legendas em tempo real

A extensão utiliza o sistema de legendas nativo do Google Meet (botão "CC") para capturar o que é falado. Nenhum áudio é gravado — apenas o texto das legendas já geradas pelo Meet.

4

Envio ao backend a cada 60 segundos

A cada minuto, o trecho de conversa capturado é enviado ao servidor do SALEIA (VPS em nuvem). O servidor processa com DeepSeek e retorna uma análise completa em segundos.

5

Cenário ao vivo com módulo Condução

O vendedor acessa o painel de cenário da reunião em tempo real. O menu Condução permite gerar scripts personalizados — Recapitulação, Apresentação (Programa de Aceleração ou Performance) e Fechamento — adaptados ao perfil DISC e temperatura do cliente.

6

Sessão salva automaticamente no banco de dados

Toda a transcrição e análise ficam salvas. Após a reunião, o vendedor acessa o dashboard para revisar, copiar a transcrição, gerar análise completa ou adicionar à base de conhecimento.

7

Base de conhecimento que aprende com o tempo

O vendedor pode exportar qualquer reunião para a Base de IA. O sistema gera um embedding vetorial da conversa. Nas próximas reuniões, a IA consulta reuniões similares para contextualizar melhor as dicas.

Funcionalidades Principais
🔐

Autenticação e Controle de Acesso

Login com e-mail e senha. Cadastro de novos usuários com aprovação. Recuperação de senha por e-mail. Três perfis: admin (acesso total), gerente (relatórios + equipe) e usuário (apenas próprias reuniões). Bearer token JWT armazenado em localStorage.

👥

Gerenciamento de Usuários (Admin)

Painel exclusivo para administradores com tabela de todos os usuários. Ações disponíveis: ativar, inativar, redefinir senha, excluir, alterar perfil e alterar plano. Qualquer tentativa de acesso sem token de admin retorna 401/403 com mensagem amigável.

🔌

Configuração de Provedores de IA (Admin)

Painel para cadastrar e gerenciar chaves de API de cada provedor (DeepSeek, OpenAI, Anthropic, Gemini). Permite testar conexão, ativar/desativar e definir qual é o provedor principal. Chaves salvas no backend; o frontend nunca recebe o valor real — apenas mascara a existência.

🎯

Módulo Condução (Cenário ao Vivo)

No slide de Condução do painel de cenário, o vendedor abre um menu dropdown com três opções: Recapitulação, Apresentação (Programa de Aceleração ou Performance) e Fechamento. Cada opção dispara uma chamada ao backend que preenche o template de prompt correspondente com os dados do cliente e retorna o script de fala calibrado ao perfil DISC e à temperatura da negociação.

🎯

Perfil DISC em Tempo Real

A IA identifica o perfil comportamental do cliente (Dominante, Influente, Estável ou Consciente) analisando palavras, ritmo e padrão de resposta. O vendedor recebe orientações específicas: como se comunicar, o que evitar, gatilhos emocionais que funcionam para aquele perfil.

💰

Diagnóstico Financeiro Automático

Extrai da conversa dados como faturamento mensal, salário CLT, limite de cartão de crédito, capacidade de investimento — e recomenda automaticamente qual produto oferecer (Base, Intermediário ou Completo) com justificativa.

🌡️

Temperatura de Negociação

Indica se o cliente está Frio, Morno, Quente ou Pronto para Fechar. Atualiza a cada análise conforme a conversa evolui. A temperatura alimenta diretamente a calibração do módulo Condução.

💬

Próxima Fala Sugerida

A IA sugere exatamente o que o vendedor deve falar a seguir, adaptado ao perfil DISC identificado e ao momento da negociação (abertura, desenvolvimento, fechamento, tratamento de objeção).

🛡️

Detecção e Resposta a Objeções

Identifica objeções do tipo "está caro", "preciso pensar", "não tenho dinheiro" e sugere a resposta ideal com base no perfil do cliente e nas técnicas de vendas consultivas.

⚠️

Alertas Urgentes

Quando o cliente dá um sinal de compra forte ou diz algo crítico que pode custar o fechamento, a IA exibe um alerta destacado para o vendedor agir imediatamente.

📊

Score de Compra (0–100)

Pontuação que indica a probabilidade de fechamento com base no comportamento, engajamento e sinais financeiros captados durante a reunião. O score alimenta a calibração do Fechamento no módulo Condução.

📚

Base de Conhecimento com RAG

Reuniões exportadas para a base ficam disponíveis para a IA consultar. O sistema usa busca semântica vetorial (RAG) para encontrar reuniões similares e contextualizar melhor as análises futuras.

Metodologia DISC

O DISC é uma das metodologias comportamentais mais utilizadas no mundo para vendas consultivas. O SALEIA identifica o perfil automaticamente durante a conversa e adapta todas as sugestões e scripts do módulo Condução para o perfil detectado.

D

Dominante

Direto, orientado a resultados, impaciente. Quer ver ROI rápido. Decisor rápido. Não gosta de rodeios. Scripts Condução: objetivo, foco em números e velocidade.

I

Influente

Emotivo, sociável, gosta de histórias de sucesso. Precisa de entusiasmo e conexão pessoal. Scripts Condução: animado, foco em transformação e reconhecimento.

S

Estável

Cauteloso, leal, resistente a mudanças. Precisa de segurança, garantias e tempo para decidir. Scripts Condução: acolhedor, foco em suporte e progressão gradual.

C

Consciente

Analítico, detalhista, compara tudo. Precisa de dados concretos, provas e lógica. Scripts Condução: lógico, foco em métricas e previsibilidade do processo.

Tecnologias Utilizadas

Stack atual da versão 1.3.3 com DeepSeek como provedor primário de IA.

IA Principal
DeepSeek Chat V3
Modelo de linguagem primário do SALEIA. Responsável por todas as análises, perfil DISC, diagnóstico financeiro e módulo Condução. Custo significativamente menor que GPT-4o mantendo qualidade comparável.
IA Fallback 1
OpenAI GPT-4o
Ativa automaticamente se o DeepSeek estiver indisponível. Circuit breaker monitora falhas consecutivas e faz a troca sem intervenção manual.
IA Fallback 2
Anthropic Claude
Terceiro provedor na cadeia de fallback. Ativa após falhas consecutivas do OpenAI. Cooldown de 60s por provedor antes de nova tentativa.
IA Fallback 3
Google Gemini
Quarto e último provedor na cadeia de resiliência. O sistema garante continuidade enquanto ao menos um provedor estiver disponível.
Embeddings / RAG
text-embedding-3-small
Modelo da OpenAI para geração de vetores semânticos. Permite busca por similaridade na base de conhecimento histórica.
Backend / API
FastAPI + Python
Framework web Python de alta performance. Processamento assíncrono nativo para atender múltiplos vendedores simultaneamente.
Servidor de Aplicação
Uvicorn
Servidor ASGI ultra-rápido. Roda com 2 workers gerenciados pelo systemd, com reinicialização automática em caso de falha.
Banco de Dados
MySQL
Armazena sessões, transcrições, análises, usuários, configurações de API e a base de conhecimento com embeddings vetoriais.
Proxy Reverso
Nginx
Recebe requisições externas e encaminha para o backend. Gerencia conexões simultâneas de forma eficiente.
CDN + HTTPS
Cloudflare
HTTPS automático, proteção DDoS, cache e DNS gerenciado. O domínio api.saleia.com.br fica protegido sem configuração manual de certificados.
Infraestrutura
VPS Hetzner
Servidor dedicado na Europa com alta disponibilidade. O serviço roda 24/7 via systemd com logs persistentes e monitoramento.
Extensão do Navegador
Chrome Extension MV3
Manifest V3. Injeta a sidebar no Google Meet, captura legendas via MutationObserver e delega fetch ao service worker para contornar bloqueios do Meet.
Busca Vetorial
NumPy (cosine similarity)
Matriz de embeddings carregada em RAM. Busca por similaridade cosseno em milissegundos sem necessidade de banco vetorial externo.
Auth
JWT Bearer Token
Tokens JWT armazenados em localStorage do browser. Endpoints protegidos com middleware de verificação de perfil (admin, gerente, usuário).

Templates de Prompt (Condução)

Os scripts do módulo Condução são gerados a partir de arquivos .txt localizados em agent/prompt_templates/. O backend carrega esses arquivos com open().read(), substitui os placeholders {variavel} com os dados do cliente e envia o prompt preenchido ao provedor de IA.


Arquivo Aciona quando Variáveis esperadas
conducao_recapitulacao.txt Menu Condução → Recapitulação perfil_disc_tipo, perfil_disc_descricao, faturamento, capacidade_investimento, produto_nome, score, temperatura
conducao_programa_aceleracao.txt Condução → Apresentação → Programa de Aceleração Idem + produto_justificativa
conducao_performance.txt Condução → Apresentação → Performance Idem + produto_justificativa
conducao_fechamento.txt Menu Condução → Fechamento Idem — calibra tom por temperatura: Alta ≥70 / Média 40–69 / Baixa <40
⚠️ Regras invioláveis dos prompts
  • Nunca inventar informações que não estejam na transcrição ou nos dados do cliente
  • Nunca expor chaves de API, tokens ou dados de infraestrutura
  • Nunca fabricar projeções financeiras sem base nos dados fornecidos
  • Nunca pressionar o cliente de forma agressiva no fechamento
  • Sempre responder em português do Brasil
  • Gerar apenas o texto da fala do vendedor — sem títulos ou explicações adicionais

Resiliência: Circuit Breaker de IA

O SALEIA nunca fica sem resposta por falha de um único provedor de IA. O sistema implementa um circuit breaker automático com quatro provedores na cadeia:


🥇
DeepSeek V3

Primário — custo otimizado e alta qualidade

🥈
OpenAI GPT-4o

Ativa após 3 falhas consecutivas do DeepSeek

🥉
Anthropic Claude

Ativa após falhas do OpenAI. Cooldown de 60s.

4️⃣
Google Gemini

Última linha de defesa na cadeia de fallback.


O provedor primário pode ser alterado pelo administrador no painel de Configuração de APIs do dashboard, sem necessidade de reiniciar o servidor.

Base de Conhecimento com RAG

RAG (Retrieval-Augmented Generation) é uma técnica onde a IA, antes de responder, consulta uma base de dados própria para enriquecer o contexto. No SALEIA funciona assim:


1

Vendedor exporta uma reunião bem-sucedida

No dashboard, clica em "📚 Adicionar à Base de IA". O sistema gera um vetor semântico (embedding) de 1536 dimensões representando o conteúdo da reunião.

2

Vetor é salvo no banco MySQL

O embedding fica armazenado na tabela base_conhecimento junto com o texto original.

3

Em novas reuniões, busca semântica é feita

A cada análise em tempo real, o sistema busca as 3 reuniões mais similares (por similaridade cosseno com NumPy). Os trechos mais relevantes são injetados no prompt da IA.

4

A IA responde com contexto histórico

A IA analisa a conversa atual já sabendo "o que funcionou em situações similares antes", gerando dicas mais precisas e personalizadas para a realidade do negócio.

Segurança e Privacidade
🔒 HTTPS em toda comunicação

Todo tráfego entre a extensão Chrome, o vendedor e o servidor é protegido por TLS/HTTPS via Cloudflare. Nenhuma informação trafega em texto puro.

🎤 Nenhum áudio gravado

O SALEIA não acessa o microfone. Utiliza apenas as legendas de texto já geradas pelo Google Meet — dados que o usuário já optou por ativar.

🔑 Chaves de API nunca no frontend

As chaves de API dos provedores de IA são armazenadas exclusivamente no backend. O dashboard exibe apenas se a chave existe (mascarada) — o valor nunca trafega para o browser.

👤 Controle de acesso por perfil

Endpoints de gerenciamento de usuários e configuração de APIs exigem perfil admin. Token JWT é verificado em cada requisição protegida. Sem token válido: 401. Sem perfil adequado: 403.

🏠 Dados no banco do cliente

Todas as transcrições e análises são salvas no banco MySQL configurado pelo cliente. Nenhum dado de reunião fica armazenado em servidores de terceiros.

⚡ XSS e Injeção bloqueados

Todo conteúdo dinâmico exibido no dashboard é escapado com escHtml(). A API usa Pydantic para validação de entrada em todos os endpoints.
